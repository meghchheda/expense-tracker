# 💰 Personal Expense Tracker

A lightweight web application built with Python to help users log, track, and manage their daily financial transactions. 

## 🚀 Live Demo
[👉 Click here to view the live application](https://expense-tracker-megh.onrender.com/)

## ✨ Features
* **Transaction Logging**: Easily record expenses with descriptions and amounts.
* **Persistent Storage**: All financial entries are saved and updated inside a CSV database.
* **Clean Interface**: Simple, user-friendly frontend dashboard to view spending history.

## 🛠️ Tech Stack
* **Backend:** Python
* **Database:** CSV (Comma-Separated Values)
* **Frontend:** HTML5, CSS3

## 💻 Local Installation & Setup
To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd expense-tracker
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python app.py
   ```
   Open your browser and navigate to `http://localhost:5000` (or the port specified in your terminal).
